# 💫 About Me

**Software Engineer & Cybersecurity Enthusiast — building local-first AI for security.**

I work at the intersection of **cybersecurity** and **applied AI**: fine-tuning language models, building
agent runtimes that execute real security tools behind an authorization gate, and writing scanners and
defensive automation in Python and Shell.

- 🐙 **Currently building:** [**Octópus**](https://github.com/erkanrzgc/octopus) — an agentic LLM for cybersecurity
- 🛡️ **Focus:** offensive & defensive security, AI-integrated tooling, agentic systems
- 💻 **Environment:** Kali Linux · VS Code · Git
- ⚡ **Interests:** LLM fine-tuning, pentesting, red/blue automation

## 🐙 Featured Project — Octópus

> An **agentic LLM for cybersecurity** — red · blue · network · Linux, with agentic tool use behind an
> authorization gate. Fine-tuned with bf16 LoRA, fluent in Turkish, and paired with an agent harness that
> parses the model's tool calls and runs the real tools through a fail-closed policy gate.
